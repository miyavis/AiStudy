# 从零造模型：五阶段路线图

> 对应总对话里"从零做一个大模型怎么做"的完整规划。量级定位：**个人从零做出一个真 LLM 的完整原理链路**（百万~千万参数），不是前沿大模型复算。

## 现实坐标

| 量级 | 内容 | 你的 4070S |
|---|---|---|
| ① 百万~千万参数小 LLM | 字符级/小 BPE，能续写、能简易对话 | ✅ 数小时~数天 |
| ② GPT-2 级（1.2 亿参数） | 预训练需数十 GB 文本 | ⚠️ 单卡勉强，1~2 周 |
| ③ 前沿大模型 | 数据工程+千卡集群+RLHF 流程 | ❌ 工业项目 |

你和前沿模型的差距在**数据与算力规模**，不在原理——原理到此全见底。

## 五阶段

### 阶段 1：Tokenizer（当前进行中，~3 天）

- [x] minbpe 源码落盘（`minbpe\minbpe\`）
- [x] demo 跑通：在你的两卷语料上训练出 288 token 词表
- [ ] 通读 `minbpe\minbpe\basic.py`（~90 行）+ 《导读-Tokenizer.md》
- [ ] 亲手实验：改 vocab_size（如 500）观察词表变化；换纯中文语料再训，看"宫/月"类 token 涌现
- 产出：**你自己的 my_tokenizer，且能逐行讲清 train/encode/decode**

### 阶段 2：从零写 Transformer（1 周）

1. `micrograd`（Karpathy）：200 行自动求导，看懂反向传播
2. 参照 `nanoGPT` 的 `model.py`（~330 行）手写：Embedding → 位置编码 → 多头自注意力 → FFN → 堆叠 → softmax
3. 学法：**视频（Karpathy《Let's build GPT》）看一遍 → 关掉自查写一遍**
- 产出：你的第一个能前向传播的 GPT 骨架

### 阶段 3：预训练（2~3 天）

- 语料建议：起步用古诗语料或月宫小说（3.1 万字），_CHAR _级小模型
- 规模：100万~500万参数，4070S 上几十分钟一个 checkpoint
- 实验：固定 prompt（如"月"）采样续写；调 temperature/top_p 复现原理篇 1.1
- 产出：模型会"接着写"，但不会"听话"——这正是下一步存在的原因

### 阶段 4：SFT 微调（周末项目）

- 数据：开源中文指令集（LLaMA 格式合集）
- 做法：对阶段 3 的检查点继续训练"指令→回答"格式
- 产出：**从"续写机器"到"听指令的助手"的贯通体验**（商用模型的 `-instruct` 后缀即此）

### 阶段 5：对齐/RLHF（阅读为主，1~2 天）

- 读懂偏好数据 → DPO/RLHF 为什么能压幻觉、学拒答
- 单卡难以完整实操，读到能向别人讲清流程即可

## 与第一卷的汇合点

理清自洽闭环：**第一卷教你调别人的模型（在"用"的层面见底），第二卷教你造一个模型（在"懂"的层面见底）**。走完阶段 4，你手里就同时有"造"和"用"两套能力——这是双螺旋，不是竞速。（详见对话记录《先做模型还是先做 agent》的结论）
